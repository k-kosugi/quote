# SKU-PROFESSIONAL

## 概要

SKU-Professional は、IT サービス管理 (ITSM) のパッケージで、Standard の機能に、AI と分析、自動化の機能を加えた上位のプランです。インシデントの振り分けや回答を自動化し、改善活動を数値で管理したい組織に向いています。

## 主な機能

Standard の機能をすべて含み、次の機能が加わります。

- **Predictive Intelligence**: 機械学習で、インシデントやリクエスト、変更の分類、担当グループの割り当て、優先度の設定を自動化する。
- **Virtual Agent**: 自然言語を理解するチャットボット。よくある問い合わせを自動で解決し、担当者への依頼を減らす。Standard は限定的な Virtual Agent Lite のみ。
- **Performance Analytics**: 傾向の分析や、時系列のダッシュボードを提供する。Standard の標準レポートより詳細に、SLA や対応時間の推移を把握できる。
- **Continual Improvement Management**: 改善の目標と施策を登録し、進捗と効果を追跡する。
- **Dynamic Translation**: チャットや対応記録を、リアルタイムに翻訳する。

## Standard との違い

| 観点 | Standard | Professional |
|---|---|---|
| インシデント、問題、変更、リクエスト | 含む | 含む |
| 自動分類と自動割り当て | なし | Predictive Intelligence |
| チャットボット | Virtual Agent Lite | Virtual Agent (フル機能) |
| 分析 | 標準のレポート | Performance Analytics |
| 継続的な改善の管理 | なし | あり |

## 向いている場面

- 問い合わせの件数が多く、一次対応を自動化したい。
- 分類や割り当ての手作業を減らし、対応の速度を上げたい。
- SLA の達成状況や改善の効果を、継続して測りたい。
