# SKU-STANDARD

## 概要

SKU-Standard は、IT サービス管理 (ITSM) の基本機能をそろえたパッケージです。インシデント、問題、変更、リクエストといった基本の業務を、1 つの基盤で管理できます。まず ITSM を始めたい組織や、基本の運用を整えたい組織に向いています。

## 主な機能

- **インシデント管理**: 障害や問い合わせを記録し、担当者への割り当てから解決までを追跡する。
- **問題管理**: 繰り返し発生するインシデントの原因を調べ、再発を防ぐ。
- **変更管理**: 変更の申請、承認、実施を管理し、変更によるリスクを減らす。
- **リクエスト管理**: サービスカタログから、利用者の依頼を受け付けて処理する。
- **構成管理 (CMDB)**: IT 資産や構成情報を管理し、インシデントや変更の影響を把握する。
- **ナレッジ管理**: 手順書や FAQ を蓄積し、利用者と担当者が参照できるようにする。
- **ワークスペースとモバイル**: 担当者向けの作業画面とモバイルアプリを提供する。
- **レポートと SLA**: 標準のレポート、SLA の管理、アンケートを提供する。
- **Virtual Agent Lite**: 限定的な機能のチャットボット。

## Professional との違い

| 観点 | Standard | Professional |
|---|---|---|
| インシデント、問題、変更、リクエスト | 含む | 含む |
| 自動分類と自動割り当て | なし | Predictive Intelligence |
| チャットボット | Virtual Agent Lite | Virtual Agent (フル機能) |
| 分析 | 標準のレポート | Performance Analytics |
| 継続的な改善の管理 | なし | あり |

## 向いている場面

- 問い合わせの件数が多くなく、基本の運用を整えたい。
- 手作業の分類や割り当てを許容でき、まず費用を抑えて始めたい。
- 将来、AI や分析の機能が必要になった時点で、Professional へ移行したい。

## 見積での扱い

- このカタログでの月額単価は、1000 円 (サンプル)。
- SKU-PROFESSIONAL とは、同じ見積に含められない。どちらか一方を選ぶ。
