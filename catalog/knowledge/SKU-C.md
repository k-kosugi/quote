# SKU-C

## 概要

SKU-C は、アプリケーションの資産管理 (APM: Application Portfolio Management) のパッケージです。組織が使っているアプリケーションを棚卸しし、費用、価値、リスクを比べて、どれを継続、統合、廃止するかを判断できるようにします。オプションの追加機能として利用します。

## 主な機能

- **アプリケーションの棚卸し**: 使用中のアプリケーションを一覧にし、担当部門、利用者、ライフサイクルの段階を管理する。
- **ビジネス能力との対応づけ**: アプリケーションを、支える業務の能力に関連づけ、重複や不足を見つける。
- **費用と価値の分析**: 運用費やライセンス費用を集計し、利用状況や業務への貢献度と比べる。
- **技術的なリスクの把握**: サポート終了や古い技術の使用などを可視化し、更新の優先順位を決める。
- **合理化の判断**: 継続、移行、統合、廃止などの方針を、アプリケーションごとに記録する。
- **構成情報との連携**: 構成管理 (CMDB) と連携し、アプリケーションが動いている基盤との関係を把握する。

## 向いている場面

- アプリケーションの数が多く、重複や使われていないものの実態をつかめていない。
- クラウドへの移行や統合の計画を、費用とリスクの根拠で説明したい。
- 更新時期が近いアプリケーションを洗い出し、予算に反映したい。
